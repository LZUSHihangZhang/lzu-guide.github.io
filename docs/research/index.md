# 科研经历与申请

科研经历不是一张必须集齐的申请清单。更重要的是确认自己想探索什么、愿意投入多少时间，以及如何把真正学到的方法和形成的判断讲清楚。

## 一个可复用的起点

1. **了解方向**：浏览学院教师主页、课程介绍和公开讲座。
2. **补足基础**：先完成一项小作业、复现或阅读笔记，形成可展示的投入。
3. **清楚地联系**：说明自己的背景、兴趣、已做准备和可投入时间。
4. **约定预期**：确认任务、指导方式、周期与成果归属。
5. **持续复盘**：记录失败、方法变化和下一步，而不只记录最终结果。

## 计划收录

- 如何联系老师与准备第一次交流
- 进入课题组后的协作和边界
- 科研实习、大创与开源项目经验
- 科研诚信、署名与材料使用

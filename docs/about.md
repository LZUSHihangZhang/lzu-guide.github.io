# 关于这本指南

这是一份面向兰大学生的经验手册，主要聚焦于海外院校申请、保研、考研及就业。大部分内容为校友的经验分享。

我们按照学院对经验贴进行分类，除此之外还有一些单开的帖子，聚焦于科研经历、海内外访问或交换等。

注意⚠️：本指南为民间项目，内容并非完全正确，信息也可能过时，因此重要通知请查阅兰州大学官网！

## 我们想解决什么


<div class="guide-banner">
  作为一名兰大的学生，从我入学起，就听说过许多校友的传奇故事。本科期间，我一直走在试错->纠错的路上，贯穿其间的，是历届学长学姐的帮助和支持。饮水思源，在我成功上岸之际，我希望将这些经验分享并记录，留给后人参考，并总结出属于自己的经验录。

  院校从不因其本身而伟大，促成其伟大的是其间的师生，以及从中走出来的天下英雄。

                                                        -2023级yyz
</div>

我们希望收集历届校友的经验贴，构筑起属于我们自己的“悟道石壁”，由此能给后来者更多的参考。

江山代有才人出。

## 阅读提醒

::: warning 重要
培养方案、评奖评优、推免、考试、费用等信息都可能变化。本站经验只能作为线索，做决定前请再次核对学校和学院的最新通知。
:::

一篇经验不等于标准答案。建议你比较不同年份、专业和目标的文章，再形成适合自己的方案。

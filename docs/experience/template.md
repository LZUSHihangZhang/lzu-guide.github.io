# 经验文章写作模板

复制下面的结构到一个新的 Markdown 文件中，删掉不需要的提示即可。

```markdown
---
title: 你的文章标题
description: 用一句话说明文章适合谁阅读
---

# 你的文章标题

## 背景

- 入学年份：
- 学院 / 专业方向：
- 目标或结果：
- 写作时间：
- 署名方式：实名 / 化名 / 匿名

## 为什么写这篇文章

你遇到了什么问题？这篇文章主要想帮助哪类读者？

## 准备过程与时间线

按阶段记录关键行动、选择依据和信息来源。

## 关键选择

当时有哪些选项？你如何比较？哪些条件影响了最终决定？

## 踩过的坑

哪些做法效果不好？为什么？

## 如果重新来一次

你会保留什么，又会改变什么？

## 参考链接

- 优先填写学校、学院或项目官方页面
```

提交前，请再次检查是否含有个人隐私、内部材料或无法公开的聊天记录。

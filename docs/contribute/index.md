# 如何分享经验

感谢你愿意把走过的路写下来。首版推荐通过 GitHub 贡献；仓库上线后，本页会补上直接入口。

## 投稿标题格式

为了便于读者检索，也方便网站按年份、去向和学院整理文章，所有投稿请使用统一标题：

```text
日期 - [类型] - [国家或地区] 年级 - 署名 - 去向 @ 院校或单位
```

例如：

**2026-08-30 - [申请] - [US] 22 - 某某 - PhD @ Columbia University**

标题中的每一部分含义如下：

| 字段 | 填写要求 | 示例 |
| --- | --- | --- |
| 日期 | 投稿或文章完成日期，统一使用 `YYYY-MM-DD` 格式 | `2026-08-30` |
| 类型 | 从 `保研`、`考研`、`申请`、`就业` 中选择一项 | `[申请]` |
| 国家或地区 | 使用常见英文缩写；国内填写 `CN` | `[US]`、`[CN]`、`[UK]`、`[HK]` |
| 年级 | 填写本科入学年份的后两位 | `22` 表示 2022 级 |
| 署名 | 可以填写真实姓名、昵称，也可以直接写“匿名” | `某某`、`小兰`、`匿名` |
| 去向 | 升学投稿填写学位类型；就业投稿填写职位名称 | `PhD`、`MPhil`、`MSc`、`学硕`、`专硕`、`学博`、`工博`、`算法工程师` |
| 院校或单位 | 全名、正式英文名或常用缩写均可 | `Columbia University`、`PKU`、`北京大学`、`北大` |

其他示例：

- **2026-09-15 - [保研] - [CN] 22 - 匿名 - 学硕 @ PKU**
- **2026-09-20 - [考研] - [CN] 21 - 小兰 - 专硕 @ 北京大学**
- **2026-10-01 - [就业] - [CN] 22 - 某同学 - 算法工程师 @ 某科技公司**

::: tip 填写提醒
请保留标题中的方括号、短横线和 `@`。各部分之间使用 ` - ` 分隔，不确定如何填写时，可以先按照最接近的示例提交，维护者会协助调整格式。
:::

## 三种方式

### 1. 提交 Pull Request（推荐）

复制[经验文章模板](/experience/template)，在合适栏目中新建 Markdown 文件，然后发起 Pull Request。维护者会协助排版、检查链接和保护隐私。

### 2. 通过 Issue 投稿

不会 Git 也没关系。仓库已准备结构化的“经验投稿”表单，可以直接填写正文或附上文档链接。

### 3. 联系维护者代为整理

正式发布前会在这里补充公开联系渠道。支持实名、化名或匿名分享。

## 审稿关注什么

- 内容是否来自真实经历，或清楚标注了信息来源
- 是否说明了年份、背景与适用范围
- 是否把个人判断误写成普遍规则
- 是否包含隐私、内部材料或侵权内容
- 标题和结构是否便于后来者搜索

## 一篇好经验不需要“成功学”

失败、改道、没有拿到理想结果的经历同样重要。具体、诚实、能解释选择条件，比华丽的结果更能帮助读者。

## 投稿后的流程

1. 维护者检查隐私、结构和失效链接。
2. 如有必要，与作者确认事实或做匿名化处理。
3. 合并后，网站自动更新并记录文章修改历史。

# 升学与就业路径总览

这部分借鉴“飞跃手册”的核心思路：让走过不同路径的人留下真实背景、准备过程、关键选择与复盘，而不是只展示结果。

## 四条常见路径

| 路径 | 建议尽早了解 | 本站计划重点记录 |
| --- | --- | --- |
| 保研 | 资格规则、成绩与科研准备 | 夏令营、预推免、联系导师与择校 |
| 考研 | 科目、院校与复习周期 | 时间安排、资料选择、复试与调剂 |
| 留学 | 语言、科研、选校与材料 | 申请时间线、项目比较、文书与预算 |
| 就业 | 方向、技能与实习 | 信息渠道、简历、面试与选择 offer |

## 使用经验帖的方法

先看作者的年级、专业、目标与时间，再看方法。结果相似的人，过程未必可以复制；背景不同的人，也可能提供更有价值的决策方式。
